# AudioTour mobile

Ứng dụng khách tham quan dùng React Native và Expo. POI, Tour, QR, audio, ảnh và tuyến đường được lấy từ Content API.

Chạy `npm ci` rồi `npm start` để mở Expo. Content API chạy riêng tại cổng `8002`; xem `scripts/README.md` để chọn IP và kiểm tra kết nối. Dùng `npm run typecheck` để kiểm tra TypeScript.
